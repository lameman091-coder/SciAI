 SciAI
Seriously Smart. Surprisingly Fun.
SciAI is an AI-powered science learning platform designed to make studying more engaging, interactive, and personalized through intelligent search, gamification, quizzes, tests, audio learning, and research tools.
Built using Kotlin, Jetpack Compose, Python, FastAPI, FAISS, and LLM technologies, SciAI bridges the gap between traditional education and modern AI-assisted learning.
